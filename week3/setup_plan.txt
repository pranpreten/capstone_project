[할 일 목록]
------------------------------------------------------------

1. Conda 가상환경 생성
   - 이름: week3_opencv
   - Python 버전: 3.10 (OpenCV 호환성 안정적)
   - 명령어: conda create -n week3_opencv python=3.10 -y

2. 필요 라이브러리 설치
   - opencv-python        : OpenCV 기본 모듈
   - opencv-contrib-python: OpenCV 추가 모듈 (CUDA 관련 등)
   - numpy                : 배열/행렬 연산
   - matplotlib           : 히스토그램 그래프 출력용
   - 명령어: pip install opencv-python opencv-contrib-python numpy matplotlib

3. 실습용 샘플 이미지/영상 다운로드
   - Lenna.png (이미지 읽기/출력, 그레이스케일, 색분리, HSV, 히스토그램 등)
   - Candies.png (색상 영역 검출 실습)
   - Hawkes.jpg (히스토그램 평활화/스트래칭)
   - desert.jpg (히스토그램 역투영)
   - test_video.mp4 (동영상 재생 - Kaggle에서 수동 다운로드 필요)

4. 실습 예제 코드 작성 (PDF의 day3 폴더 구조 기준)
   - ex1_opencv_readImg.py          : 이미지 파일 읽기/출력
   - ex2_opencv_readVideo.py        : 동영상 파일 읽기/출력
   - ex3_opencv_readCam.py          : 카메라 영상 읽기/출력
   - ex4_opencv_split.py            : BGR 채널 분리
   - ex5_opencv_cvtColor_HSV.py     : 색 공간 변경 (HSV)
   - ex5_opencv_cvtColor_YUV.py     : 색 공간 변경 (YUV) [실습]
   - ex6_opencv_extractColor_RGB.py : RGB 색상 영역 검출
   - ex7_opencv_extractColor_HSV.py : HSV 색상 영역 검출 (빨간색)
   - ex7_opencv_extractColor_HSV_blue.py : HSV 파란색 캔디 추출 [실습]
   - ex8_opencv_histogram_gray.py   : 그레이스케일 히스토그램
   - ex8_opencv_histogram_bgr.py    : BGR 히스토그램
   - ex9_opencv_adjustWBR.py        : 명암비 조작
   - ex10_opencv_equalizeHist.py    : 히스토그램 평활화
   - ex11_opencv_normalizeHist.py   : 히스토그램 스트래칭
   - ex12_opencv_backproj.py        : 히스토그램 역투영
   - ex13_opencv_filtering.py       : 이미지 필터링 (평균, 샤프닝, 라플라시안)
